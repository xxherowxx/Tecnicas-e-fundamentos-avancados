# Super Trunfo em C

Tema 2 - Super Trunfo em c: Fundamentos e Técnicas Avançadas, com o objetivo de aplicar os **fundamentos da lógica de programação** utilizando a linguagem **C**, por meio do jogo Super Trunfo.

## Objetivo
Aplicar conceitos básicos de programação na construção da lógica de um jogo de cartas, reforçando o aprendizado de estruturas fundamentais da linguagem C.

## Conteúdos Abordados
- Variáveis e tipos de dados  
- Entrada e saída de dados  
- Estruturas condicionais (`if` e `else`)  
- Estruturas de repetição  
- Uso de `struct`  
- Fluxo lógico do jogo Super Trunfo  

## Tecnologias
- Linguagem C  
- Git  
- GitHub  

## Observação
Este repositório contém **material teórico** com fins didáticos, não sendo um programa executável.
